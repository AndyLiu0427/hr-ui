Component Props
Prop Type Default Description
tabs TabItem[] required Array of tab items with id and label
activeTab string '' Two-way binding for active tab ID (supports ngModel)
interactive boolean true False makes the whole strip inert: no click, no keyboard, and anchor tabs drop their href so the context menu cannot navigate either
TabItem Interface
Property Type Description
id string Unique identifier for the tab
label string Display text for the tab
description string? Optional extra text announced with the tab via aria-describedby
href string? Present when selecting the tab navigates rather than swapping content in place. Renders an anchor with role="link" and aria-current instead of a role="tab" button; left-click is still preventDefaulted so the caller routes
Events
Event Type Description
tabChange EventEmitter<string> Emits the selected tab ID when a tab is clicked
