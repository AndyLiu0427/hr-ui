Sizes States Prefix and Suffix Loading Clearable Adds an X that empties the field, shown only once it holds a value. Reach for it on any optional field a reader may fill in by mistake — above all type="date": Chrome and Safari render no clear control of their own, so without this the only way back to empty is to select the text and delete it, which readers do not find. Clearing sets the value to an empty string, which is what the API reads as "clear this field" — distinct from omitting the field, which leaves the stored value alone.
