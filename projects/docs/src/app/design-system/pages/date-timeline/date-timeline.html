Component Props
Prop Type Default Description
nodes DateTimelineNode[] required Milestones to render, positioned proportionally to their date distances. Nodes without a date are omitted; the strip renders nothing when every node is dateless. Dates of near-coincident nodes alternate above and below the track.
DateTimelineNode Interface
Property Type Required Description
date string | Date | null Yes Rendered as dd MMM (years live on the year-boundary ticks); a falsy value drops the node
emphasis boolean No Accent-colored dot and date; the track from this node to the end of the span is drawn in the accent color as well
