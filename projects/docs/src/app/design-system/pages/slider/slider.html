Component Props
Prop Type Default Description
leftPercent number required Left side percentage (0-100)
rightPercent number required Right side percentage (0-100)
leftLabel string required Label for left side
rightLabel string required Label for right side
leftColor 'primary' | 'neutral' 'primary' Color variant for left side
rightColor 'primary' | 'neutral' 'neutral' Color variant for right side
showLabels boolean false Whether to show labels below the slider
showTicks boolean false Whether to show clickable percentage ticks (0, 10, 20, ..., 100) below the slider. Users can click any tick to jump directly to that percentage.
step number 1 Movement step size (1-100). Controls how much the slider moves per action. For example, step=10 allows only 0, 10, 20, ..., 100 values.
Events
Event Payload Description
percentageChange {{ '{' }} left: number, right: number {{ '}' }} Emitted when percentages change (debounced 300ms).
sliderClick void Emitted when slider is clicked (not dragged). Useful for navigation actions.
