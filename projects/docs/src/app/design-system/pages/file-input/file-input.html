File Input Native file picker with two visual modes — dropzone + preview for single-file flows (e.g. company logo), and a compact inline button for multi-file toolbars (e.g. attachments).
Preview mode Default mode. Renders a dropzone with thumbnail preview, button, and help text. Validates MIME type + size (via accept + maxFileSize).
Empty state @if (previewSelectedName()) { Selected: {{ previewSelectedName() }} } Disabled
Button mode Bare button that opens the picker — no preview, no validation. All oct-button props pass through (color, variant, size, icon, iconOnly, loading). Use projected content for the label.
Upload Outline Ghost Compact (iconOnly on mobile) Uploading… Disabled
@if (buttonSelectedNames().length > 0) {
Last picked: {{ buttonSelectedNames().join(', ') }} Reset
}
API
Inputs (both modes)
  • mode: 'preview' | 'button' — default 'preview'
  • accept: comma-separated mime / extension list — default '' (all)
  • multiple: allow picking many files — default false
  • disabled, loading
Inputs (preview mode only)
  • preview: external DataURL / image src
  • maxFileSize: bytes — default 5 MiB; null disables
  • placeholderIcon, error, labels
Inputs (button mode — oct-button passthrough)
  • color, variant, size
  • icon, iconPosition, iconOnly
  • fullWidth, ariaLabel
Outputs
  • filesSelected: File[] — single-file callers read $event[0]
  • previewChanged: string | null — preview mode DataURL changes
  • removeFile: void — preview-mode remove button
  • validationError: string — preview-mode validation failure
Usage 
<!-- Preview mode (default) — image upload with dropzone -->
<oct-file-input
  [preview]="logoPreview()"
  [labels]="logoLabels()"
  (filesSelected)="onLogoSelected($event[0])"
  (removeFile)="removeLogo()" />

<!-- Button mode — inline multi-file picker -->
<oct-file-input
  mode="button"
  variant="outline"
  icon="Upload"
  [multiple]="true"
  [loading]="uploading()"
  (filesSelected)="onFiles($event)">
  Upload
</oct-file-input>
