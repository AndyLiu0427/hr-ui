Input Select An amount and the unit it is measured in, as one control. Two signal-forms fields inside one bordered shell, sharing one label and one error row.
Quick presets: Default Filled With Error Disabled

Examples Paired validation The two halves are one value, so each requires the other. The whole shell turns red and one message names the missing half. The error shows as soon as EITHER half is touched.
Component Props
Prop Type Default Description
amountField FieldTree<string> required Signal-forms field for the amount. Carries the label's `for` target.
unitField FieldTree<string> required Signal-forms field for the unit
unitOptions SelectOption[] [] Unit choices. Also sizes the dropdown height.
label string undefined One label for the pair. Also names the unit for screen readers.
placeholder string '' Placeholder for the amount half
unitPlaceholder string '' Placeholder for the unit half
helperText string undefined Helper text, replaced by the error message when invalid
size 'sm' | 'md' | 'lg' 'md' Size of both halves
