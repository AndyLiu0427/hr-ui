Component Props
Prop Type Default Description
options SearchSelectOption[] [] Array of selectable options (for static options)
value string | number | (string | number)[] | null null Currently selected value (supports two-way binding with model()). Holds an array when multiple is enabled.
placeholder string '' Placeholder text when no value is selected
label string '' Label text above the search select
size 'sm' | 'md' | 'lg' 'md' Size of the search select component
disabled boolean false Disable the search select component
error boolean false Show error state
errorText string undefined Error message to display in error state
required boolean false Mark the field as required
clearable boolean false Show clear button when value is selected
multiple boolean false Enable multi-select. Value becomes an array; trigger shows "N selected" and the dropdown stays open while toggling
