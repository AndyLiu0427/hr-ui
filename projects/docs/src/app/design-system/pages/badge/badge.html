Dismissible Badges Badges with dismiss functionality are commonly used in multi-select dropdowns, tag inputs, and filter chips.
Component Props
Prop Type Default Description
text string 'Badge' The text content of the badge
icon string undefined Material icon name to display
size 'sm' | 'md' | 'lg' 'sm' Size of the badge component
mode 'solid' | 'opacity' 'solid' Visual style of the badge
color 'neutral' | 'success' | 'warning' | 'error' | 'info' 'neutral' Color theme of the badge
dismissible boolean false Shows an X button to dismiss the badge
(dismiss) EventEmitter<void> - Emitted when the dismiss button is clicked
