Why the stroke changes with size Lucide draws on a 24 grid at every size, so its declared stroke is scaled by size/24. hr-icons switches to a dedicated 16-unit master at 18px and below. One stroke value cannot match both, so oct-icon uses 1.875 at 16px and 1.5 above — measured to within 0.1% of the same ink.
