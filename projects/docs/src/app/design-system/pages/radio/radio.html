Radio Component Presentational single-select control. The parent owns the checked state and mutual exclusion — ideal for picking one row among several (e.g. choosing one billing rate when more than one matches).
Preview @for (option of options; track option.value) { } Selected: {{ selected() }}
Configuration Selecting any radio replaces the previous selection within the same group. Clicking the already-selected radio does not deselect it (single-select keeps one choice).

Component Props
Prop Type Default Description
checked boolean false Whether the radio is selected (controlled by the parent)
disabled boolean false Disables interaction
label string undefined Optional visible label text
description string undefined Always-visible helper text under the label (needs label to show)
name string undefined Group name so the browser enforces single-select
ariaLabel string undefined Accessible label when no visible label is shown
htmlValue string undefined Native input value attribute
Component Events
Event Type Description
radioChange boolean Emitted (true) when the user selects this radio
