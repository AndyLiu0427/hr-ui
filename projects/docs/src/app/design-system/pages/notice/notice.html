Dismissible notices allow users to close them You can dismiss this notice by clicking the X button.
Long Content This is a longer notice message that demonstrates how the component handles multiple lines of text. The notice component automatically wraps text and maintains proper spacing and alignment between the icon, content, and dismiss button even with longer messages.
Component Props
Prop Type Default Description
variant 'info' | 'success' | 'warning' | 'error' 'info' Visual style of the notice
icon string | null null Custom icon name from Lucide
showDefaultIcon boolean true Show variant's default icon
dismissible boolean false Show dismiss button
showAction boolean false Show action button
actionLabel string 'View' Label for the action button
class string '' Additional CSS classes
Component Events
Event Type Description
dismiss void Emitted when the notice is dismissed
actionClick void Emitted when the action button is clicked
