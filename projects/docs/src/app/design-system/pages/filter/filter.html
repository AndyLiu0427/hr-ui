API
Inputs
Name Type Default Description
label string required The label displayed on the filter button
options FilterOption<T>[] required Array of filter options to display in the menu
selectedValues unknown[] [] Currently selected values (supports two-way binding with [(selectedValues)])
width string | number '280px' Width of the filter menu overlay
offsetY number 8 Vertical offset from the button in pixels
searchable boolean false Enable inline search input for filtering checkbox options
searchPlaceholder string 'Search...' Placeholder text for the search input
Outputs
Name Type Description
filterChange unknown[] Emitted when filter selections change, returns array of selected values
menuOpened void Emitted when the filter menu opens
menuClosed void Emitted when the filter menu closes
