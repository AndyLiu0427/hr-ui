Career Progression A career read as a tree: each contract is a period, the clients served during it hang beneath it, and each client's assignments hang beneath that.
Contracts, clients and assignments A contract carries dates only, because one contract can cover several clients. The topmost contract's node is green while it has not ended. One client, one assignment Job title is optional: an assignment without one shows its department and dates. Empty State When no contracts are provided, the tree shows an empty state message.
