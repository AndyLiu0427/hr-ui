Inline editing Fully generic — the table is oct-table<T> and imposes no row shape; editing is driven purely by per-column config, so any table can opt in without new types. Set editable on a column to make its cells click-to-edit. Use editType: 'number' with editMin / editInteger for numeric validation, or a per-row predicate editable: (row) => … to lock specific rows (row 3 below). Columns without editable (e.g. Name) stay read-only. Committing a change emits (cellValueChange) with the row, column, rowIndex and value. Click a value, edit it, then press Enter (or click away); Esc cancels.
