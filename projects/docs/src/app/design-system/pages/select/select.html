Component Props Core Properties
Prop Type Default Description
options SelectOption[] [] Array of options to display. Set option.disabled to show as disabled and non-selectable.
value string | number | null null Currently selected value (two-way bindable with model())
placeholder string 'Select an option' Placeholder text when no value is selected
label string undefined Label text above the select
description string undefined Description text below label
helperText string undefined Helper text below the select (when no error)
errorText string undefined Manual error message override
Signal Forms Integration (FormValueControl<T>)
Prop Type Default Description
errors readonly ValidationError[] [] Validation errors array from Signal Forms
touched boolean false Whether the field has been touched (input; the control emits (touch) when the user leaves it)
dirty boolean false Whether value has been modified
pending boolean false Whether async validation is pending
invalid boolean false Whether field is invalid
disabled boolean false Disable the select component
required boolean false Whether field is required
Appearance
Prop Type Default Description
size 'sm' | 'md' | 'lg' 'md' Size of the select component
fullWidth boolean false Make select take full width of container
showIcon boolean true Show option icons in dropdown
hideHelper boolean false Hide helper/error text area
error boolean undefined Manual error state override
showScrollIndicators boolean true Show scroll indicators when list is scrollable
Behavior
Prop Type Default Description
clearable boolean false Show clear button when value is selected
multiple boolean false Enable multiple selection mode with badge display
maxDisplay number | undefined undefined Maximum badges to display before showing "+N more" (multiple mode only)
loading boolean false Show loading spinner
maxHeight string '240px' Maximum height of dropdown menu
Performance
Prop Type Default Description
virtualScrolling boolean false Enable virtual scrolling for large datasets (1000+ items)
itemSize number 40 Item height in pixels (for virtual scrolling)
Events
Event Type Description
selectChange string | number | null | (string | number)[] Emitted when selection changes (value only)
selectionChange SelectOption | SelectOption[] | null Emitted when selection changes (full option object)
selectFocus FocusEvent Emitted when select receives focus
selectBlur FocusEvent Emitted when select loses focus
